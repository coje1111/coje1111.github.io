## 참조값은 무엇이고 왜 필요할까?

배열 강의에서 참조값이라는 설명을 보고, 수학 공식처럼 외워야 하는 것인지 궁금했다. `students`에 `x001`을 저장한다는 그림도 실제로 어떤 코드를 쓰라는 뜻인지 바로 이해되지 않았다.

```java
int[] students = new int[5];
```

`new int[5]`는 정수를 담을 칸 다섯 개짜리 배열을 만든다. 각 칸의 초기값은 `0`이다. `students` 변수에는 숫자 다섯 개가 통째로 들어가는 것이 아니라, **만들어진 배열을 가리키는 참조값**이 저장된다.

```text
students → 참조하는 배열 [0, 0, 0, 0, 0]
```

배열을 나중에 찾아 사용하려면 그 배열을 가리키는 값이 필요하다. 우리는 참조값을 직접 계산하지 않고, 변수 이름을 통해 배열을 사용한다.

```java
students[0] = 90; // students가 가리키는 배열의 첫 칸에 90을 저장한다.
```

강의의 `x001`은 이 관계를 보여주기 위한 설명용 표식이다. 실제 코드에 `students = x001;`이라고 작성하거나 그 값을 외우라는 뜻이 아니다.

## 배열을 출력하면 나오는 값은 실제 주소일까?

“참조값을 출력해서 볼 수 있다”는 설명을 듣고, 실제 출력과 강의의 표식을 어떻게 구분해야 할지도 궁금했다.

```java
System.out.println(students);
```

예를 들어 다음과 같은 문자열이 나올 수 있다.

```text
[I@2f92e0f4
```

- `[I`: `int` 배열임을 나타내는 표시다.
- `@` 뒤의 부분: 이 배열 객체의 해시값을 16진수로 표시한 것이다.

이것은 배열을 문자열로 표현한 결과이며, 실제 메모리 주소 자체를 그대로 보여주는 것은 아니다. 해시값은 객체를 구분하는 데 쓰이는 숫자이지만 서로 다른 객체에서 중복될 수도 있다.

같은 배열을 반복해서 출력하면 같은 표시가 나온다. 그 배열 안의 숫자를 바꿔도 동일한 배열이므로 표시는 유지된다.

```java
System.out.println(students);
students[0] = 90;
System.out.println(students); // 같은 배열이므로 앞과 같은 표시가 나온다.
```

그렇다고 프로그램 실행마다 무조건 달라지는 랜덤 번호도 아니다. 다른 컴퓨터나 다시 실행한 프로그램에서는 같은 표시가 나올 수도, 다른 표시가 나올 수도 있다. **강의 화면과 내 출력값이 같아야 하는 것은 아니다.**

또한 `println(students)`가 참조값을 새로 만드는 것은 아니다. 배열은 이미 `new int[5]`에서 만들어졌고, 이 줄은 변수가 참조하는 배열의 문자열 표현을 출력할 뿐이다.

## 배열의 각 칸을 for문으로 읽기

학생 점수를 배열에 넣고, 반복문으로 출력하는 코드를 보면서 배열과 `for`문이 어떻게 연결되는지 이해할 수 있었다.

```java
package array;

public class Array1Ref2 {
    public static void main(String[] args) {
        int[] students;         // 배열을 가리킬 변수를 선언한다.
        students = new int[5];  // 배열을 만들고 참조값을 저장한다.

        students[0] = 90;
        students[1] = 80;
        students[2] = 70;
        students[3] = 60;
        students[4] = 50;

        for (int i = 0; i < students.length; i++) {
            System.out.println("학생" + (i + 1) + " 점수: " + students[i]);
        }
    }
}
```

출력 결과는 다음과 같다.

```text
학생1 점수: 90
학생2 점수: 80
학생3 점수: 70
학생4 점수: 60
학생5 점수: 50
```

반복문을 쓰지 않으면 출력 부분은 다음처럼 각 칸을 직접 지정하게 된다.

```java
System.out.println("학생1 점수: " + students[0]);
System.out.println("학생2 점수: " + students[1]);
System.out.println("학생3 점수: " + students[2]);
System.out.println("학생4 점수: " + students[3]);
System.out.println("학생5 점수: " + students[4]);
```

이 다섯 줄은 같은 일을 하고, 학생 번호와 배열의 칸 번호만 달라진다. 그 달라지는 부분을 `i`로 바꾼 것이 반복문 버전이다.

## i, i + 1, length의 역할 나누기

| i | 읽는 배열의 칸 | 저장된 점수 | 화면에 표시할 학생 번호 |
|---:|---|---:|---:|
| 0 | `students[0]` | 90 | 1 |
| 1 | `students[1]` | 80 | 2 |
| 2 | `students[2]` | 70 | 3 |
| 3 | `students[3]` | 60 | 4 |
| 4 | `students[4]` | 50 | 5 |

배열의 칸 번호인 인덱스는 `0`부터 시작하므로 `students[i]`로 접근한다. 사람이 읽을 학생 번호는 `1`부터 보여주려고 출력에서만 `(i + 1)`을 사용한다. 이 계산으로 변수 `i` 자체가 증가하는 것은 아니다.

`students.length`는 배열의 칸 수이고, 여기서는 `5`다. 따라서 조건은 `i < students.length`이며, `i`가 `0`부터 `4`일 때 실행되고 `5`가 되면 반복이 끝난다.

`i <= students.length`라고 쓰면 존재하지 않는 `students[5]`까지 읽으려 해 배열 범위 초과 오류가 발생한다. 칸 수가 5개인 것과 마지막 칸 번호가 4인 것을 구분해야 한다.

## 배열과 반복문이 연결되면서 보인 개선점

배열을 더 큰 배열로 바꾸고 그에 맞게 점수를 준비해도, 출력 반복문은 수정할 필요가 없다. `students.length`를 기준으로 모든 칸을 읽기 때문이다. 단, 이미 만들어진 배열의 길이를 나중에 바꾸는 것은 아니고 필요한 길이의 배열을 새로 만드는 것이다.

반복문을 언제 응용하는지 추상적으로 들었을 때보다, **“같은 출력 작업에서 대상만 달라진다”**는 모습을 보니 훨씬 구체적으로 이해됐다. 다섯 개의 출력문이 하나의 반복문으로 정리되는 과정이 신기하고 재미있었다.

- 참조값: 변수가 어떤 배열을 가리키는지 연결한다.
- `students[i]`: 그 배열에서 이번에 사용할 칸을 고른다.
- `for`: 칸 번호를 바꾸면서 같은 작업을 반복한다.
- `students.length`: 배열의 길이에 맞춰 반복 범위를 정한다.
