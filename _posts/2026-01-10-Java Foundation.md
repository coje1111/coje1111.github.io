## 2026-08-03 추가 학습: 조건식이 없는 `for`문과 `break`

### 궁금했던 점

`for`문은 보통 다음과 같이 초기식, 조건식, 증감식으로 구성된다.

```java
for (초기식; 조건식; 증감식) {
    // 반복할 코드
}
```

그런데 아래 코드처럼 가운데 조건식을 생략하고 세미콜론(`;`)만 남겨도 실행되는 이유가 궁금했다.

```java
int sum = 0;

for (int i = 1; ; i++) {
    sum += i;

    if (sum > 10) {
        System.out.println("합이 10보다 크면 종료: i=" + i + ", sum=" + sum);
        break;
    }
}
```

### 조건식을 생략하면 계속 반복한다

`for`문의 조건식을 생략하면 Java는 반복 조건이 항상 참인 것처럼 동작한다.

```java
for (int i = 1; ; i++)
```

위 코드는 다음 뜻으로 읽을 수 있다.

> `i`를 1로 시작하고, 반복이 끝날 때마다 `i`를 1씩 증가시킨다. 조건식이 없으므로 계속 반복한다.

두 개의 세미콜론은 초기식, 조건식, 증감식의 자리를 구분하므로 조건식을 생략해도 그대로 남겨야 한다.

### `for`, `if`, `break`의 역할

처음에는 `if`문도 반복문의 일부인지 헷갈렸다. 각각의 역할을 나누면 다음과 같다.

- `for`: 중괄호 안의 코드를 반복하는 **반복문**
- `if`: 주어진 조건이 참인지 검사하는 **조건문**
- `break`: 자신을 감싸는 가장 가까운 반복문을 즉시 끝내는 **명령문**

```text
for 반복문
└─ sum에 i를 더한다
└─ if 조건문으로 sum > 10인지 검사한다
   └─ 조건이 참이면 break가 for문을 끝낸다
```

즉, 이 코드는 다음 한 문장으로 기억할 수 있다.

> `for`가 반복하고, `if`가 멈출 조건을 확인하고, `break`가 반복을 멈춘다.

### 실제 실행 흐름

각 반복에서 `sum`은 다음과 같이 변한다.

```text
i=1 → sum=1
i=2 → sum=3
i=3 → sum=6
i=4 → sum=10
i=5 → sum=15 → sum > 10이 참 → break
```

따라서 출력 결과는 다음과 같다.

```text
합이 10보다 크면 종료: i=5, sum=15
```

`break`가 실행되면 `for`문을 즉시 빠져나가므로 그 뒤의 증감식 `i++`는 실행되지 않는다.

### `while (true)`와 비교

같은 흐름을 `while`문으로도 작성할 수 있다.

```java
int sum = 0;
int i = 1;

while (true) {
    sum += i;

    if (sum > 10) {
        System.out.println("합이 10보다 크면 종료: i=" + i + ", sum=" + sum);
        break;
    }

    i++;
}
```

두 코드의 동작은 같다. 다만 숫자 `i`의 시작과 증가를 한곳에 모아 보고 싶다면 `for`문이 편하고, 어떤 사건이 생길 때까지 계속 실행한다는 점을 강조하고 싶다면 `while (true)`가 자연스럽게 읽힐 수 있다.

처음부터 이 표현 차이까지 구분하려고 애쓸 필요는 없다. 현재는 아래처럼 단순하게 기억한다.

- 숫자를 일정하게 증가시키며 반복하면 우선 `for`
- 조건을 확인하며 반복하면 우선 `while`
- 조건식이 없는 `for`문은 내부의 `break`가 있는지 확인

### 주의할 점

조건식을 생략했는데 `break`, `return`, 예외 발생 같은 종료 방법도 없다면 반복문은 끝나지 않는다.

```java
for (;;) {
    // 종료 방법이 없으면 무한 반복
}
```

또한 `if` 안의 `break`는 `if`문을 끝내는 명령이 아니다. `if`는 반복문이 아니므로, `break`는 `if`를 감싸는 가장 가까운 `for`문이나 `while`문을 종료한다.

### 배운 점

- 코드 문법을 한꺼번에 외우기보다 각 요소의 역할을 분리해서 보면 이해하기 쉽다.
- `for`문 전체가 반복문이고, 그 중괄호 안에 `if` 조건문과 `break` 명령문이 들어갈 수 있다.
- 조건식이 없는 `for`문은 계속 반복하며, 이 예제에서는 `sum > 10`일 때 실행되는 `break`가 종료 시점을 정한다.
- 핵심 흐름은 **`for`가 반복하고 → `if`가 검사하고 → `break`가 멈춘다**이다.
