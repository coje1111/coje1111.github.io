## 배웠던 배열과 누적 계산을 연결해 보기

배열을 반복문으로 읽는 방법과 숫자의 합계·평균을 구하는 방법을 각각 배웠지만, 다시 작성하려니 바로 떠오르지 않았다. 이번 글은 스스로 풀어낸 과정을 적은 것이 아니라, AI가 제공한 풀이를 읽으며 복습하기 위한 학습 노트다.

문제는 다음 배열에 들어 있는 모든 점수의 합계와 평균을 구하는 것이다.

```java
int[] scores = {90, 80, 70, 60, 50};
```

이 선언은 점수 다섯 개가 들어 있는 배열을 만든다. 앞에서 배운 `new int[5]`로 배열을 만든 뒤 각 칸에 값을 넣는 방법과 달리, 만들 때 넣을 값들을 함께 적은 형태다.

풀이 순서를 말로 먼저 정리하면 다음과 같다.

1. 합계를 저장할 변수를 0으로 준비한다.
2. 배열의 첫 칸부터 마지막 칸까지 점수를 하나씩 읽어 더한다.
3. 반복이 끝나면 합계를 출력한다.
4. 점수가 있다면 합계를 점수 개수로 나누어 평균을 출력한다.

## 전체 풀이

```java
public class ArrayScoreReview {
    public static void main(String[] args) {
        int[] scores = {90, 80, 70, 60, 50};
        int sum = 0; // 반복이 끝날 때까지 합계를 기억한다.

        for (int i = 0; i < scores.length; i++) {
            sum += scores[i]; // 이번 칸의 점수를 기존 합계에 더한다.
        }

        System.out.println("점수 합계: " + sum);

        if (scores.length > 0) {
            double average = (double) sum / scores.length;
            System.out.println("점수 평균: " + average);
        } else {
            System.out.println("점수가 없어 평균을 계산할 수 없습니다.");
        }
    }
}
```

결과는 합계 `350`, 평균 `70.0`이다. `Scanner`는 사용하지 않는다. 이번에는 키보드로 점수를 받는 것이 아니라, 배열에 이미 넣어 둔 점수를 읽기 때문이다.

## 반복할 때 무엇이 바뀌는지 따라가기

`i`는 배열에서 읽을 칸 번호이고, `scores[i]`는 그 칸에 들어 있는 점수다. `scores.length`는 칸의 개수인 `5`다.

```java
for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
}
```

`i`는 `0`에서 시작한다. 조건이 맞으면 점수를 더하고, `i++`로 칸 번호를 1 늘린 뒤 다시 조건을 확인한다.

| i | 이번에 읽는 값 | 더하기 전 sum | 더한 뒤 sum |
|---:|---:|---:|---:|
| 0 | `scores[0]` → 90 | 0 | 90 |
| 1 | `scores[1]` → 80 | 90 | 170 |
| 2 | `scores[2]` → 70 | 170 | 240 |
| 3 | `scores[3]` → 60 | 240 | 300 |
| 4 | `scores[4]` → 50 | 300 | 350 |

그다음 `i`가 `5`가 되면 `5 < 5`는 거짓이므로 반복이 끝난다. `scores[5]`는 읽지 않는다. 칸은 다섯 개지만 번호는 `0`부터 `4`까지다.

`sum += scores[i]`는 다음 코드와 같은 뜻이다.

```java
sum = sum + scores[i];
```

기존 합계에 이번 점수를 더한 결과를 다시 `sum`에 저장한다. `sum = scores[i]`라고만 쓰면 앞서 더한 값이 덮어써져 마지막 점수 `50`만 남는다.

## 변수와 계산을 이 위치에 놓는 이유

`sum`은 **앞서 더한 결과를 다음 반복에서도 사용하고, 반복이 끝난 뒤 출력**해야 하므로 `for`문 밖에 선언한다.

반복문 안에서 매번 `int sum = 0;`을 실행하면 이전 합계를 이어서 쌓지 못한다. 또한 그 중괄호 안에서 선언한 변수는 중괄호 밖에서 사용할 수 없다.

반면 `i`는 칸을 고르는 동안만 필요하므로 `for`문의 초기식에 선언한다. `average`는 점수 개수를 확인한 뒤 계산하고 출력하면 되므로 `if` 안에 선언한다.

최종 평균도 반복문 밖에서 구한다. 모든 점수를 더한 뒤 계산해야 최종 결과가 된다. 반복문 안에서 출력하면 최종 결과 한 번이 아니라, 점수를 더할 때마다 중간 결과가 나오게 된다.

이전의 숫자 입력 문제에서는 입력 개수를 `count++`로 셌지만, 이번에는 배열의 모든 점수를 사용하므로 `scores.length`가 개수다. 일부 점수만 골라 계산한다면 그때는 실제로 더한 점수의 개수를 따로 세어야 한다.

## 평균에는 왜 (double)을 붙일까?

`int`끼리 나누면 소수 부분이 버려진다. 결과를 받을 변수만 `double`로 선언한다고 이미 버려진 소수 부분이 돌아오지는 않는다.

```java
double average = sum / scores.length; // 정수끼리 먼저 나눈다.
double average = (double) sum / scores.length; // 나누기 전에 실수로 바꾼다.
```

위 두 줄은 비교용이며, 실제 코드에서는 둘 중 하나만 사용한다. `(double) sum`은 이번 계산에서 `sum`의 값을 소수를 표현할 수 있는 형태로 바꾼다는 뜻이다. 변수 `sum` 자체는 여전히 `int`다.

원래 점수는 `350 / 5`가 딱 나누어떨어져 차이를 놓치기 쉽다. 첫 점수만 `90`에서 `91`로 바꾸면 합계 `351`, 평균 `70.2`가 되어 차이가 드러난다. 정수끼리 먼저 나누면 `70.0`이 된다.

점수가 없는 배열도 생각할 수 있다.

```java
int[] scores = {};
```

이때 반복문은 한 번도 실행되지 않고 합계는 `0`이다. `scores.length > 0` 검사 덕분에 평균을 계산하지 않고 안내를 출력한다. 검사가 없으면 이 식에서는 `0.0 / 0`이 되어 정상적인 숫자가 아니라는 뜻의 `NaN`이 나온다.

이번 예제는 소수의 학생 점수를 다루는 연습이다. 매우 많은 수를 더해 `int`가 표현할 수 있는 범위를 넘는 상황은 별도로 고려해야 한다.

## 복습할 때 확인할 것

기본 코드를 Java 17에서 실행해 다음 결과를 확인했다.

```text
점수 합계: 350
점수 평균: 70.0
```

배열 값만 바꿔 추가로 실행한 결과도 확인했다.

- `{91, 80, 70, 60, 50}` → 합계 `351`, 평균 `70.2`
- `{}` → 합계 `0`, 점수가 없어 평균을 계산할 수 없다는 안내

다시 공부할 때는 전체 코드를 바로 외우기보다 다음 질문에 답하며 읽어 본다.

- `i`가 `2`이면 이번 점수는 무엇인가? → `scores[2]`에 있는 `70`이다.
- 합계를 왜 0부터 시작하는가? → 아직 더한 점수가 없고, 0에 첫 점수를 더하면 된다.
- `sum`을 왜 반복문 밖에 두는가? → 합계를 이어서 쌓고 반복 후에도 사용해야 한다.
- `count` 없이 어떻게 평균을 구하는가? → 모든 칸을 사용하므로 `scores.length`가 개수다.

그다음 첫 점수를 `91`로 바꾸거나 배열을 비워 보고, 실행 전에 예상한 결과와 비교해 보면 된다. 핵심은 **배열에서 하나씩 읽기 → 합계에 계속 더하기 → 반복이 끝난 뒤 개수로 나누기**다.
