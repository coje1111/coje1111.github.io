## 헷갈렸던 점

짝수·홀수 판별 문제에서 강의는 `number % 2 == 0`으로 짝수를 먼저 확인했다. 나는 `number % 2 == 1`로 홀수를 먼저 확인하고, 나머지는 짝수로 출력했다.

음이 아닌 정수에서는 두 방식의 판별 결과가 같지만, 음수까지 입력할 수 있다면 차이가 생긴다.

## 음수의 나머지도 생각하기

Java에서 `%`는 나눗셈의 나머지를 구한다. 음수인 홀수를 2로 나누면 나머지가 `-1`이 된다.

```java
System.out.println(3 % 2);  // 1
System.out.println(-3 % 2); // -1
```

따라서 `number % 2 == 1`로 검사하면 `-3`은 조건을 만족하지 않아 `else`로 넘어가고, 짝수라고 잘못 출력된다.

홀수를 먼저 확인하려면 `!= 0`, 즉 **나머지가 0이 아닌지** 검사하면 된다.

```java
if (number % 2 != 0) {
    System.out.println("홀수입니다.");
} else {
    System.out.println("짝수입니다.");
}
```

## 기억할 것

- 짝수 확인: `number % 2 == 0`
- 홀수 확인: `number % 2 != 0`
- `0`도 나머지가 `0`이므로 짝수로 판별한다.
- 위 두 방식은 음수를 포함한 모든 `int` 값에서 같은 홀짝 판별 결과를 내며, 먼저 확인하고 싶은 쪽을 선택하면 된다.
