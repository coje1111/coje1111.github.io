## 강의를 따라 하다가 발견한 작은 개선점

음식 이름, 가격, 수량을 입력받아 총가격을 출력하는 문제를 풀었다. 강의에서는 `30000 × 5`의 결과를 `150000원`처럼 숫자만 이어서 출력했다.

계산은 맞았지만 금액이 커질수록 바로 읽기 어려웠다. 강의에는 쉼표를 넣는 방법이 나오지 않아, **“150,000원처럼 보이게 만들 수 있을까?”**라는 의문을 갖고 개선 방법을 질문했다.

`String.format()`을 사용하면 계산은 그대로 두고 출력 모양만 바꿀 수 있다는 것을 배웠다. 정답을 따라 작성하는 데서 한 걸음 더 나아가, 내가 읽기 편한 결과를 만들기 위한 작은 개선으로 이어졌다.

## String.format으로 금액 표시하기

```java
int totalPrice = 30000 * 5;

// 계산한 금액을 읽기 편한 출력용 문자열로 바꾼다.
String formattedPrice = String.format("%,d", totalPrice);

System.out.println("총 가격은 " + formattedPrice + "원입니다.");
```

한국 지역 설정에서의 출력 형태는 다음과 같다.

```text
총 가격은 150,000원입니다.
```

`totalPrice`는 계산용 숫자 `150000` 그대로다. `formattedPrice`는 쉼표가 들어간 출력용 문자열 `"150,000"`이다.

## 기호와 사용 방법을 하나씩 이해하기

방법을 알아도 `"%,d"`가 어떻게 동작하는지 궁금해 기호를 하나씩 나눠 확인했다.

### 여기서 %도 나머지를 구한다는 뜻일까?

```java
number % 2                  // 계산식의 %: 나머지를 구한다.
String.format("%,d", 150000) // 문자열 속 %: 표시 방법의 시작이다.
```

따옴표 안의 `%`는 나머지 연산자가 아니다. `String.format()`이 문자열을 읽으면서 **“여기에 값을 넣고, 뒤에 적힌 방법대로 표시하라”**는 표시로 해석한다.

| 기호 | 이 예제에서의 의미 |
|---|---|
| `%` | 값을 표시할 형식 지정의 시작 |
| `,` | 숫자에 세 자리 구분 기호 사용 |
| `d` | 전달받은 정수를 십진수로 표시 |

이 기호의 의미는 Java가 정해 놓은 약속이다. `%,d`는 “정수를 표시하면서 세 자리 구분 기호를 넣어라”라고 읽으면 된다.

### ‘뒤에 전달하는 값’은 무엇일까?

```java
String.format("%,d", totalPrice)
```

첫 번째 값인 `"%,d"`는 **어떻게 표시할지**, 두 번째 값인 `totalPrice`는 **무엇을 표시할지** 정한다.

즉, “`totalPrice`의 값을 받아서 정수로 표시하되 세 자리마다 구분 기호를 넣어줘”라는 뜻이다. 따옴표 안의 쉼표는 구분 기호 옵션이고, 따옴표 밖의 쉼표는 함수에 전달하는 두 값을 나눈다.

### format은 따로 설치해야 하는 기능일까?

`String.format()`은 Java가 기본으로 제공하는 메서드, 즉 호출해서 사용할 수 있는 기능이다. 별도로 설치할 필요 없이 표시 방법과 값을 전달하면 문자열을 만들어 돌려준다.

```java
String message = String.format("가격은 %,d원입니다.", 150000);
System.out.println(message);
```

`format`은 형식을 맞춘다는 뜻이다. 문자열을 만들어 주지만 화면에 직접 출력하지는 않으므로, 출력은 `System.out.println()`이 담당한다.

구분 기호는 지역 설정에 따라 달라질 수 있다. 한국 방식으로 명시하려면 상단에 `import java.util.Locale;`를 추가하고 `String.format(Locale.KOREA, "%,d", totalPrice)`로 사용할 수 있다.

## 기억할 것

- `%d`: 전달한 정수를 표시한다.
- `%,d`: 정수를 세 자리 구분 기호와 함께 표시한다.
- `String.format(표시 방법, 표시할 값)`의 두 역할을 구분한다.
- 숫자를 문자열로 바꾸는 시점은 계산할 때가 아니라 사용자에게 보여줄 때다.
