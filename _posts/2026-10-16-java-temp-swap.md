## temp는 특별한 기능일까?

변수의 값을 바꾸는 예제에서 `temp`가 어떤 역할인지 궁금했다. `temp`는 temporary(임시의)를 줄인 이름으로, 잠깐 값을 보관하는 변수에 흔히 붙인다. Java에 정해진 특별한 명령은 아니다.

## 덮어쓰기 전에 원래 값을 복사한다

```java
int a = 10;
int b = 20;

int temp = a; // a의 원래 값 10을 복사해 보관한다.
a = b;        // a에 20을 넣는다.
b = temp;     // 보관한 10을 b에 넣는다.
```

결과는 `a = 20`, `b = 10`이다. `temp = a`는 값을 빼내는 동작이 아니므로, 이 줄 직후에는 `a`와 `temp` 모두 `10`을 가지고 있다.

임시 보관 없이 `a = b; b = a;`라고 쓰면 첫 줄에서 원래 `a`의 값 `10`을 잃는다. 두 번째 줄은 이미 바뀐 `a`를 읽으므로 둘 다 `20`이 된다.

## 변수 세 개의 값도 돌릴 수 있다

세 개라면 먼저 각 값을 어디에 넣을지 정한다. 아래 예제는 `a`에 원래 `b`, `b`에 원래 `c`, `c`에 원래 `a`의 값을 넣는다.

```java
int a = 10;
int b = 20;
int c = 30;

int temp = a;
a = b;
b = c;
c = temp;
```

결과는 `a = 20`, `b = 30`, `c = 10`이다. 이런 순환 교환에는 임시 변수 하나면 충분하다.

## 중괄호가 끝나면 자동으로 복구되는 것은 아니다

처음에는 원래 값을 잠시 보관하고 다른 코드에서 계산한 뒤, 중괄호가 끝나면 그 값을 다시 불러오는 방식인지 헷갈렸다.

`temp`는 보통 변수일 뿐이다. 중괄호가 끝난다고 값이 자동으로 돌아오지 않으며, 원래 변수에 되돌리고 싶다면 직접 대입해야 한다.

```java
int a = 10;
int temp = a;

a = 20;
a = temp; // 보관한 값을 직접 대입해 a를 10으로 되돌린다.
```

값을 교환할 때처럼 보관한 값을 다른 변수에 넣을 수도 있다. 핵심은 **나중에 필요한 값이 덮어써지기 전에 복사해 두고, 사용할 위치를 코드로 지정하는 것**이다.
