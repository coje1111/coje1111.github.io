# coje1111.github.io

개발 학습 과정을 기록하는 개인 GitHub Pages 블로그입니다.

이 저장소는 프로젝트 진행 중 겪은 문제, 디버깅 과정, 해결 방법, 새로 배운 개념을 나중에 다시 보기 위한 학습 기록으로 관리합니다.

## 기록 방식

- 게시글은 `_posts` 폴더에 작성합니다.
- 글은 완료된 작업 단위로 정리합니다.
- 단순 작업 로그보다 문제 상황, 원인 분석, 해결 과정, 배운 점을 중심으로 기록합니다.
- 공개 저장소이므로 민감한 정보나 개인 로컬 경로는 기록하지 않습니다.

## 게시글 형식

Jekyll 기본 게시글 형식을 사용합니다.

```md
---
layout: post
title: "게시글 제목"
---
```

파일명은 다음 형식을 따릅니다.

```text
YYYY-MM-DD-title.md
```
